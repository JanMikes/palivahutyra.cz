# Paliva Hutyra

Website for a family-owned fuel business in Frýdek-Místek, Czech Republic.

**Live site:** [palivahutyra.cz](https://palivahutyra.cz)

## Tech Stack

- [Astro](https://astro.build) - Static site generator
- [Tailwind CSS](https://tailwindcss.com) - Styling

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
